# 管理室の使い方（Claude Code・Pro プラン向け）

制作は Codex、事務は Claude Code の「管理室」が受け持ちます。
管理室は **利用枠をなるべく使わない** ように作ってあります。

| 担当 | 呼び方 | 仕事 | 使うAI |
|---|---|---|---|
| 秘書A | `/dandori` | 今週の段取り（予定・期日・やること） | 軽いAI |
| メール係A | `/mail` | メールの仕分けと返信の下書き | 軽いAI |
| 経理A | `/kicho` | 領収書から経費の記録 | 軽いAI |
| 経理A | `/getsumatsu 2026-09` | 月の経費の集計 | 計算は道具、説明だけ軽いAI |
| 書類係A | `/shorui 請求書 …` | 見積書・請求書・納品書 | 通常のAI（金額と番号は道具） |
| 監査A | `/kansa ファイルの場所` | 外に出す前の確認（Codex の完成物も） | 通常のAI |
| 整理係A | `/katazuke` | 済んだ物の保管 | 軽いAI |

**AIがメールを送ったり、お金を払ったり、ファイルを消したりすることはありません。**

---

## 利用枠を節約する仕組み

1. **決まった仕事は、呼び方（`/dandori` など）で頼む。**
   その担当のやり方だけを読み込むので、余計な読み込みがありません。
2. **単純な仕事は、軽いAIが受け持つ。**
   仕分けや記帳は、Claude の軽いモデル（Haiku）で動きます。枠の減りが少なくて済みます。
3. **計算はAIにさせない。**
   金額・消費税・書類番号・期日・集計は `道具/` の小さなプログラムが計算します。道具は枠を使いません。計算の間違いも起きません。
4. **1つの仕事が終わったら `/clear` と打つ。**
   会話が長くなるほど、1回ごとの枠の減りが大きくなります。仕事ごとに会話をまっさらにするのが、一番の節約です。
5. **週に1回まとめて頼む。**
   例：月曜の朝に `/dandori` → `/mail` → `/kicho` → `/katazuke`。

---

## はじめの準備（1回だけ）

1. **Node.js が入っているか確かめる**：ターミナル（Mac）か PowerShell（Windows）で `node -v`。数字が出ればOK。出なければ https://nodejs.org から「LTS」を入れる。
2. **このフォルダをパソコンに持ってくる**：GitHub の緑の「Code」→「Download ZIP」。中の `ai-company` フォルダだけを、好きな場所に置く。
3. **会社情報を書く**：`会社情報.md` の【】を自分の情報に書き換える。

## 毎回の使い方

1. `ai-company` フォルダで Claude Code を起動する（`cd …/ai-company` → `claude`）。初めての時は「このフォルダを信頼しますか」に「はい」。
2. `dashboard/index.html` をダブルクリックして、組織図を開いておく（担当が動くと数秒で光ります）。
3. 処理してほしい物（メールの文面・領収書の写真など）を `受け取り/` に入れて、呼び方で頼む。

### 頼み方の例
```
/dandori
/mail
/kicho
/getsumatsu 2026-09
/shorui 請求書 山田工務店 棚の製作 1式 88,000円（税抜）10%
/kansa 書類/請求書/INV-2026-0001_山田工務店.html
/katazuke
```

## Codex の完成物を確かめる時

Codex で作った物のファイルの場所を、そのまま `/kansa` に渡します。

```
/kansa C:\Users\…\codexの作業フォルダ\紹介文.md
```

監査A は **読むだけで、書き換えません**。見る項目は `.claude/skills/kansa/チェック表.md` にあります。項目は自由に書き足せます。

---

## 道具を直接使う（AIも枠も使わない）

ターミナルで `ai-company` フォルダに移って、次のように打つと、道具だけを動かせます。

```
node 道具/期日.mjs
node 道具/集計.mjs 2026-09
node 道具/次の番号.mjs 請求書
node 道具/計算.mjs "棚の製作,1,88000,10" "お菓子,3,333,8"
```

## 担当を増やす（B・C…）

1. `.claude/skills/mail` フォルダをコピーして `.claude/skills/mail-b` にする。
2. 中の `SKILL.md` の2行目を `name: mail-b` に、「メール係A」を「メール係B」にする。
3. `/mail-b` で呼べるようになり、組織図にも「メール係B」として自動で並びます。

## できた物の置き場所

| 物 | 場所 |
|---|---|
| メールの下書き | `書類/メール下書き/` |
| 見積書・請求書・納品書 | `書類/見積書/` など（ブラウザで開いて印刷すると PDF にできます） |
| 経費・入出金・請求・支払い | `台帳/` の CSV（Excel で開けます） |
| 予定・やること | `台帳/予定.md` `台帳/やること.md` |
| 済んだ書類 | `保管/年/月/` と `保管/目録.csv` |

`受け取り/` や `書類/` の中身は、GitHub には上がらない設定にしてあります。

## うまく動かない時

- **組織図が「見本の動き」のまま**：Claude Code を `ai-company` フォルダで起動しているか確かめる。
- **記録の設定を見たい**：Claude Code の中で `/hooks`。
- **使える呼び方を見たい**：Claude Code の中で `/` と打つと一覧が出ます。
