# AI事務員の使い方

Claude Code に「事務員」の担当を7つ用意しました。仕事を頼むと、まとめ役が各担当に割り振ります。
誰が働いているかは、組織図の画面で見られます。

| 担当 | 任せること |
|---|---|
| まとめ役 | 頼みごとを聞いて割り振り、まとめて報告する |
| メール係A | メールの仕分けと返信の下書き |
| 秘書A | 予定の整理、日程調整の文面、やることリスト |
| 書類係A | 見積書・請求書・納品書 |
| 整理係A | 済んだ物に名前を付けて保管 |
| 経理A | 領収書から経費の記録、月の集計 |
| 入金・支払い係A | 入金の確認、支払い期日の一覧 |
| 確認係A | 外に出す前の最終確認 |

**AIがメールを送ったり、お金を払ったりすることはありません。** 作るのは下書きと一覧までです。

---

## はじめの準備（1回だけ）

### 1. Node.js が入っているか確かめる
動きの記録に使います。ターミナル（Mac）か PowerShell（Windows）で次を打ちます。

```
node -v
```

`v20.…` のように数字が出れば大丈夫です。エラーになったら https://nodejs.org から「LTS」と書かれた方を入れてください。

### 2. このフォルダをパソコンに持ってくる
GitHub のこのリポジトリを、`git clone` するか、緑の「Code」ボタン →「Download ZIP」で持ってきます。
使うのは中の `ai-company` フォルダだけです。好きな場所（例：書類フォルダ）に置いて構いません。

### 3. 会社情報を書く
`会社情報.md` を開いて、【】の所を自分の情報に書き換えます。書類やメールの署名に使われます。

## 毎日の使い方

### 1. `ai-company` フォルダで Claude Code を起動する

```
cd ai-company のある場所/ai-company
claude
```

初めての時に「このフォルダを信頼しますか」と聞かれたら「はい」を選びます。

### 2. 組織図の画面を開いておく
`dashboard/index.html` をダブルクリックすると、ブラウザで開きます。
担当が動くと、数秒で札が光ります。札を押すと、その担当の仕事と最後の報告が見られます。

### 3. 仕事を頼む
処理してほしい物（メールの文面、領収書の写真など）を `受け取り/` に入れて、Claude Code に話しかけます。

頼み方の例：
- 「受け取りの中を片付けて」
- 「山田工務店あてに、棚の製作 1式 88,000円（税抜）で請求書を作って」
- 「今月の経費を勘定科目ごとに集計して」
- 「今週払うものと、まだ入金されていない請求を教えて」
- 「来週の予定を整理して、やることリストも更新して」

## できた物の置き場所

| 物 | 場所 |
|---|---|
| メールの下書き | `書類/メール下書き/` |
| 見積書・請求書・納品書 | `書類/見積書/` `書類/請求書/` `書類/納品書/`（ブラウザで開いて印刷すると PDF にできます） |
| 経費・入出金・請求・支払いの一覧 | `台帳/` の CSV（Excel で開けます） |
| 予定・やること | `台帳/予定.md` `台帳/やること.md` |
| 済んだ書類 | `保管/年/月/` と `保管/目録.csv` |

`受け取り/` や `書類/` の中身は、GitHub には上がらない設定にしてあります。

## 担当を増やす（B・C…）

仕事が多い係を増やす時は、`.claude/agents/` の中の同じ係のファイルをコピーします。

1. 例えば `mail-a.md` をコピーして `mail-b.md` にする
2. ファイルの2行目 `name: mail-a` を `name: mail-b` に
3. 3行目の「メール係A」を「メール係B」に

組織図は、メール係Bが初めて動いた時に、自動で「受付・メール」の列に並びます。
まとめ役は、仕事が多い時に A と B に分けて同時に任せます。

## 担当の仕事の中身を変える

各担当のやり方は `.claude/agents/〇〇.md` に日本語で書いてあります。書き換えれば、その通りに動きます。
事務所全体の決まり（送信しない・消さない など）は `CLAUDE.md` にあります。

## うまく動かない時

- **組織図が「見本の動き」のまま**：Claude Code を `ai-company` フォルダで起動しているか確かめてください。別の場所で起動すると、担当も記録も読み込まれません。
- **記録の設定を確かめたい**：Claude Code の中で `/hooks` と打つと、記録係の設定が一覧で見られます。
- **Codex もつなぎたい**：今は Claude Code だけに対応しています。必要なら言ってください。
