# チェック表（監査A）

外に出す物は、全部の項目を見る。当てはまらない項目は「対象外」と書く。

## 1. 約束との一致
- [ ] 依頼・見積もり・合意した内容と、中身が合っている
- [ ] 数量・範囲・納期が、合意したものと同じ

## 2. 相手
- [ ] 会社名・名前・敬称（様／御中）が正しい
- [ ] 別のお客様の名前や情報が残っていない

## 3. お金
- [ ] 明細の計算が合う（道具で計算し直した）
- [ ] 消費税が税率ごとに正しい
- [ ] 振込先・インボイス登録番号が `会社情報.md` と同じ

## 4. 日付
- [ ] 日付と曜日が合っている
- [ ] 期限が過去になっていない

## 5. 言葉
- [ ] 誤字・脱字・表記ゆれがない
- [ ] 【要確認】や【】が残っていない
- [ ] 言い過ぎがない（「必ず稼げる」「絶対」「世界初」「No.1」など、根拠のない言い方）
- [ ] 修正回数・追加料金などの条件が、決めた内容と同じ

## 6. 出してはいけない情報
- [ ] 今の勤務先の図面・お客様・社内の情報が入っていない
- [ ] 社内のAI運用の詳しいやり方が入っていない
- [ ] 他人の個人情報（住所・電話・口座など）が、必要以上に入っていない

## 7. 見た目（ホームページ・画像の時）
- [ ] スマホの幅で、文字がはみ出たり切れたりしていない
- [ ] リンクが正しい先に飛ぶ
